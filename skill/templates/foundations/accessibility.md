## Accessibility

Baseline: **WCAG 2.2 Level AA**, organized on the POUR principles.

### Perceivable
[Contrast floors: text ≥ 4.5:1, non-text UI ≥ 3:1. Text alternatives for non-text content.]

### Operable
[Keyboard access for all interactions. Visible focus. Minimum target size 24×24 CSS px.]

### Understandable
[Consistent navigation and labeling. Clear error identification and messages.]

### Robust
[Valid semantics/ARIA. Tested with a screen reader before a component is "done".]
